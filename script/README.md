# script 目录说明

本目录用于存放与项目运行、部署、初始化和历史底座资源相关的辅助文件。

## 当前结构

- `bin/`
  - 主应用启动/停止脚本
- `bpmn/`
  - 工作流相关资源
- `docker/`
  - Docker 编排与镜像运行辅助文件
- `sql/`
  - 初始化脚本与升级脚本

## 使用建议

### `bin/`

当前仅覆盖 `ruoyi-admin.jar` 的基础启动管理。

适用场景：

- 本地或简单服务器手工运行参考

限制：

- 不覆盖 `ruoyi-monitor-admin`
- 不覆盖 `ruoyi-snailjob-server`
- 不体现多服务依赖关系

### `bpmn/`

工作流相关资源目录。

说明：

- 当前工作流模块未纳入现行聚合构建
- 该目录先作为遗留资源保留，不建议未经确认直接删除

### `docker/`

Docker 相关文件目录。

请先阅读：

- [README.md](/E:/flower-sharing/script/docker/README.md)

### `sql/`

SQL 脚本目录，包含：

- 基础初始化脚本
- 多数据库方言脚本
- 版本升级脚本

说明：

- 当前业务运行主要基于 MySQL
- 其他数据库脚本多来自底座遗留，后续需进一步确认保留策略

## 当前治理原则

- 先补说明，不急于重写全部脚本
- 不在未确认生产使用方式前删除脚本
- 不把脚本整理伪装成业务改造
