# 回归检查清单

本清单用于后续每次清洗和改造后的回归参考。

当前先以“人工可执行 + 后续可脚本化”为目标。

回归范围说明：

- 本清单默认服务于单商户标准商城主线
- `ruoyi-demo` 与 `ruoyi-generator` 默认不纳入商城回归主线
- 如某次改动直接涉及 `ruoyi-demo` 或 `ruoyi-generator`，应单独补充专项验证
- 当前接口暴露面基线见 `docs/architecture/api-surface.md`

## 1. 后台基础能力

- 后台登录是否正常
- 后台权限校验是否正常
- 菜单和路由是否正常加载
- Swagger 页面是否可访问

## 2. 商品体系

- 商品列表查询是否正常
- 商品详情查询是否正常
- 分类查询是否正常
- SKU/规格相关接口是否正常
- 商品后台新增或编辑是否正常

## 3. 订单体系

- 订单列表查询是否正常
- 订单详情查询是否正常
- 后台订单状态流转是否正常
- 小程序下单接口是否正常
- 订单取消是否正常

## 4. 支付体系

- 支付下单参数生成是否正常
- 微信支付回调接口是否仍可访问
- 支付成功后的订单状态变更是否正常
- 退款链路是否仍可触发

## 5. 物流体系

- 发货/配送相关后台接口是否正常
- 订单物流信息查询是否正常
- 小程序物流详情或配送查询是否正常

说明：

- 当前物流模型带有鲜花遗留语义，改动时应重点回归

## 6. 会员与积分

- 会员等级查询是否正常
- 会员权益相关接口是否正常
- 积分获取/扣减相关接口是否正常
- 积分商品或积分订单相关接口是否正常

## 7. 优惠券与营销基础

- 优惠券领取是否正常
- 优惠券使用是否正常
- 与下单金额联动是否正常

## 8. 小程序核心链路

- 首页或商品入口是否正常
- 分类浏览是否正常
- 商品详情是否正常
- 加购物车是否正常
- 提交订单是否正常
- 支付链路是否正常
- 我的订单是否正常

## 9. 本次明确不纳入主干但需防误伤的遗留能力

- 课程
- 社区/花友圈
- 鲜花专属配送扩展
- 推广计划/返利类能力

说明：

- 这些不属于目标主干
- 但在正式剥离前，改动过程中仍应防止误伤

## 10. 使用方法

每次改造前：

- 先圈定可能影响的能力域

每次改造后：

- 至少回归对应能力域
- 记录“已验证 / 未验证 / 受环境限制未验证”

## 11. 后续自动化建议

优先级建议：

1. 登录与 Swagger 冒烟
2. 商品、订单关键接口冒烟
3. 小程序下单链路冒烟
4. 支付回调模拟验证
